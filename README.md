# Flit Browser 0.23.0 · Windows 개발 미리보기

Windows 11 x64 개발용 소스입니다. [설치 및 GitHub 배포 방법](installer/README.md)

AI가 일반 창과 분리된 작업 탭에서 페이지의 본문과 링크를 읽고, 0.12부터 지원되는 사이트에서는 Flit Vault로 로그인할 수 있다. [Codex 연결과 Vault 사용법](AGENT.md)

## 사용

- 주소창은 웹 주소와 검색어를 구분한다. `Ctrl+L`, `Alt+D`, `F6`으로 주소창으로 이동하고 `Enter`로 현재 탭에 연다. `Alt+Enter`는 현재 페이지를 그대로 두고 입력한 주소나 검색 결과를 새 탭에 연다. 조합 입력 중에는 입력기가 `Enter`·`Esc` 등을 먼저 처리한다. 확정된 주소창·검색 텍스트는 `Ctrl+Backspace`·`Ctrl+Delete`로 앞·뒤 단어를 지운다.
- `Ctrl+K`나 `Ctrl+E`를 누르면 주소창이 `? `로 시작한다. 주소처럼 보이는 내용도 검색하고 싶을 때 쓴다. `Esc`로 현재 페이지 주소로 돌아간다. **⋯ → Search engine**에서 DuckDuckGo, Google, Naver, Bing 중 기본 검색엔진을 선택할 수 있다. 기본값은 DuckDuckGo다.
- 기본은 **왼쪽 세로 탭**이다. `Ctrl+T`로 새 탭, `Ctrl+W`·`Ctrl+F4` 또는 탭 오른쪽 ×로 닫는다. `Ctrl+Shift+T`로 이번 실행에서 닫은 일반 탭을 원래 순서와 고정 상태로 되돌리거나, 다른 일반 창이 남아 있으면 닫은 일반 창을 다시 연다. `Ctrl+Tab`·`Ctrl+Shift+Tab`으로 다음·이전 탭, `Ctrl+1`~`Ctrl+8`로 해당 탭, `Ctrl+9`로 마지막 탭으로 이동한다.
- `Alt+Enter`나 웹페이지 링크로 열어 바로 선택된 새 탭을 닫으면, 그 탭을 열었던 페이지로 돌아간다. 출발 탭이 이미 닫혔으면 남은 탭 중 가까운 탭으로 이동한다.
- 왼쪽 탭을 끌면 삽입선이 나타난다. 탭 메뉴의 **Move tab up / down**으로도 순서를 바꿀 수 있다. 고정 탭과 일반 탭은 각 구역 안에서 옮기며, 복원이 켜져 있으면 순서가 다음 실행에도 유지된다.
- 탭을 클릭하면 키보드 입력이 웹페이지로 돌아간다. 왼쪽 목록에 포커스를 둔 채 방향키로 탭을 옮길 수 있고, `Enter`로 선택한 페이지에 포커스를 준다.
- 탭을 오른쪽 클릭하면 고정·복제·음소거할 수 있다. **Unload tab to free memory…**는 선택하지 않은 탭의 페이지를 닫고 주소·제목·고정 상태를 남긴다. 다시 선택하면 페이지를 로드한다.
- 메뉴의 **Free memory from background tabs…**는 현재 창의 백그라운드 탭을 한 번에 정리한다. 확인창에서 동의할 때만 실행한다. 고정 탭, 로딩·다운로드·카메라·마이크·DevTools를 쓰는 탭과 페이지를 떠날 때 경고하는 탭은 건너뛴다. 정리한 탭은 다시 선택하면 페이지를 로드한다. 다른 재생이나 경고 없는 임시 입력은 중단될 수 있다.
- 메신저처럼 유지할 사이트는 탭을 오른쪽 클릭해 **Keep [사이트] active when freeing memory**를 켠다. 일반 창 전체에서 같은 호스트에 적용되며 재시작 후에도 유지된다. 같은 항목을 다시 누르면 해제된다. 개별 탭을 직접 내리거나 비공개 창을 정리할 때는 적용되지 않는다.
- 링크를 백그라운드로 열면 창마다 아직 선택하지 않은 탭을 최대 두 개까지 미리 로드한다. 나머지는 탭 목록에 두고 선택할 때 로드한다. RAM이 부족하거나 **Load background links only when selected**를 켜면 모두 선택할 때 로드한다. 이미 열린 페이지는 그대로 둔다.
- 갑작스러운 종료 후 마지막 저장 시점의 일반 창과 탭을 복원한다. 일반 창은 최대 16개, 창마다 탭 주소·순서·고정 상태를 최대 128개까지 저장한다. 각 창의 선택된 탭만 먼저 로드한다. 비공개 창은 저장하지 않는다.
- 모든 창을 다음 실행에 이어가려면 **⋯ → Exit Flit (all windows)**로 종료한다. 창을 하나씩 **×**로 닫으면 마지막 일반 창만 남는다. 이전 실행의 복구본은 **⋯ → Open previous session backup**에서 현재 창을 유지한 채 열 수 있다. **Restore windows and tabs on startup**을 끄면 복원용 탭 기록을 지우고 다음에 빈 탭으로 시작한다.
- `Ctrl+N`은 새 일반 창, `Ctrl+Shift+N`은 비공개 창, `Ctrl+Shift+W`는 현재 창 닫기다. 비공개 창은 일반 창과 사이트 데이터를 공유하지 않는다. 마지막 비공개 창을 닫으면 비공개 사이트 데이터가 사라진다. 내려받은 파일은 남는다.
- 사용자가 클릭해서 여는 팝업은 원래 창과 통신할 수 있는 별도 창으로 연다. 최상위 페이지가 카메라·마이크를 요청하면 사이트 주소를 표시하고, **Allow this time**을 선택한 요청만 허용한다. 사용 중인 장치는 세로 탭과 활성 창 제목에 표시한다. 알림·화면 공유 등은 Chromium의 기본 확인창을 사용한다.
- `Ctrl+Shift+A`로 탭을 검색한다. 여러 단어를 입력하면 제목과 주소에서 함께 찾는다. `↑`·`↓`로 후보를 옮길 때는 현재 페이지를 유지하고, `Enter`를 누르면 강조된 탭을 연다. `Esc`는 탭을 바꾸지 않고 검색을 지운다. 목록 위 숫자는 검색 결과 수와 전체 탭 수다.
- 왼쪽 위 버튼이나 `Ctrl+Shift+B`로 패널을 열고 닫는다. 일반 창에서 마지막으로 고른 상태가 새 창과 다음 실행의 기본값이다. 움직이는 도중 다시 눌러 방향을 바꿀 수 있다. Windows에서 애니메이션을 끄면 즉시 전환한다.
- 페이지가 로딩되는 동안 새로고침 버튼은 **× (로딩 중지)**로 바뀐다. `Ctrl+R`·`F5`는 계속 새로고침으로 작동한다.
- `Ctrl+F`로 페이지를 검색하고 `F3`·`Ctrl+G`는 다음, `Shift+F3`·`Ctrl+Shift+G`는 이전 일치 항목으로 이동한다. `Ctrl+F5`로 캐시를 건너뛰어 새로고침하고 `F11`로 전체 화면을 전환한다. `Ctrl++`·`Ctrl+-`·`Ctrl+0`은 페이지 배율을 바꾸거나 초기화한다. 배율은 사이트별로 기억한다.
- 네이버처럼 넓은 화면을 전제로 만든 사이트가 좁은 창에서 잘리면 창을 최대화하거나, 왼쪽 패널을 접거나, `Ctrl+-`로 해당 사이트의 배율을 낮춘다.
- 별 버튼 또는 `Ctrl+D`로 현재 웹페이지를 북마크에 저장하고, `Ctrl+Shift+O`로 북마크 관리 화면을 연다. 다른 브라우저에서 내보낸 북마크 HTML을 **⋯ → Import bookmarks from HTML…**에서 골라 추가할 수 있다. Flit에서 백업할 때는 **Export bookmarks to HTML…**을 누른다. 두 메뉴는 일반 창에서만 사용할 수 있다.
- **⋯ → Move sites and bookmarks**에서 Chrome·Edge의 북마크를 파일 내보내기 없이 옮기거나, 그 사이트를 세로 탭에 준비한다. 다른 브라우저에서 복사한 사이트 주소도 여러 개 추가할 수 있다. 준비한 탭은 선택할 때 로드한다. [사이트와 북마크 옮기기](MOVE-SITES.md)
- `Ctrl+J`로 다운로드를 확인한다. 다운로드 중인 탭을 닫을 때 **Yes**를 누르면 전송을 마친 뒤 닫힌다. 기다리는 탭에는 **After download**가 표시되고, 우클릭 메뉴의 **Keep tab open after downloads**로 예약을 취소할 수 있다. 전송에 실패하거나 취소되면 탭이 남는다. 다운로드 중 창을 닫거나 Flit 전체를 종료할 때는 확인 메시지가 뜬다.
- 주소창 왼쪽 버튼으로 현재 사이트의 연결 상태를 보고, 일반 창에서 해당 사이트 설정을 바로 열 수 있다. `Ctrl+Shift+Delete`는 인터넷 사용 기록 삭제다. 일반 설정과 기록 삭제는 별도 창에서 열리므로 현재 탭을 그대로 볼 수 있다.
- `F12`·`Ctrl+Shift+I`로 현재 탭의 개발자 도구를 열고 닫으며, `Ctrl+Shift+J`로 콘솔을 연다. 메뉴에서 방문 기록, 비밀번호 관리자, 확장 관리, 인쇄도 열 수 있다.
- 다른 브라우저에서 내보낸 아이디와 비밀번호는 일반 창의 **⋯ → Import passwords from CSV… → Select file**에서 가져온다. [지원 형식과 옮기는 방법](PASSWORD-IMPORT.md)
- Windows 11 22H2 이상에서는 창 프레임에 Mica Alt를 요청한다. 메뉴에서 **Use acrylic window frame**을 선택하면 해당 실행에서 Desktop Acrylic을 요청한다. Windows의 투명 효과와 고대비 설정에 따라 단색이 될 수 있다. 주소창·탭 텍스트와 웹 콘텐츠는 불투명하게 유지한다.
- **About Flit and updates**에서 버전과 업데이트 채널 상태를 확인한다. [자동 업데이트](installer/UPDATES.md)는 서명 키와 배포 저장소를 지정한 빌드에서만 켜진다. 지금 제공한 개발 미리보기에는 실제 업데이트 채널을 연결하지 않았다.
- 기본 프로필은 `%LOCALAPPDATA%\Flit Browser\User Data`에 저장된다. 제거해도 프로필은 남는다. 기존 Chrome·Aside 프로필을 열거나 복사하지 않는다.

## 범위

현재 빌드는 **Rust + Win32 + CEF Chrome Runtime**이다. 빈 탭에는 웹 렌더러를 만들지 않고 주소를 열 때만 Chromium 탭을 만든다. 이번 빌드는 **CEF 158.0.3 베타**를 사용한다. [색과 RAM 설계](DESIGN.md) · 엔진 확인 기록

0.10.0의 변경 사항은 동작과 RAM 점검에 정리했다. 0.9.0과 Aside의 메모리 실측은 같은 로컬 페이지를 각각 새 프로필에서 불러와 비교한 결과다.

Chrome 웹 스토어, 패스키, 실제 사이트 로그인 호환성, Microsoft 한국어 IME로 직접 타이핑하는 흐름, Exact 통합은 아직 확인하지 않았다. AI 작업 탭은 읽기·링크 이동·일부 HTTPS 폼 로그인을 지원한다. 기존 사용자 탭 인계와 다단계 로그인은 지원하지 않는다. 카메라·마이크 확인창은 가상 장치로 검사했으며 알림 허용·실제 화면 공유는 검증하지 않았다. 복원은 URL을 다시 여는 기능이며, 페이지 내부 입력이나 뒤로 가기 이력은 복원하지 않는다. 현재는 서명되지 않은 개발 미리보기다.

## 빌드

[Rust CEF 바인딩](https://github.com/tauri-apps/cef-rs/tree/9aa78c450489eddb828eb982eaee6c104a89d348) `156.4.0+156.0.26`과 Rust `1.100.0`으로 API `15600`을 대상으로 컴파일한다. 배포할 때는 동일한 API를 지원하는 CEF `158.0.3+g8c29be2` / Chromium `158.0.8127.18`의 Windows x64 부트스트랩과 런타임을 묶는다. 저장소 루트에서 실행한다.

~~~bash
export CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_RUSTFLAGS='-C target-feature=+crt-static'
cargo test --release --locked --target x86_64-pc-windows-msvc --lib
cargo build --release --locked --target x86_64-pc-windows-msvc
~~~

툴체인 기록과 [설치 파일 빌드 안내](installer/README.md)를 참고한다. `tests/windows_*.py`는 별도의 테스트 프로필로 실행한다. `tests/windows_shortcuts.py --exe <Flit.exe>`는 잠금이 풀린 Windows에서 실제 키 입력을 검사한다. `tests/windows_memory.py`는 두 버전을 같은 로컬 페이지와 탭 상태로 비교한다.
