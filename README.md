# Flit Browser 0.41.0 · Windows 개발 미리보기

Flit은 Windows 11 x64용 브라우저입니다. 왼쪽 세로 탭을 기본으로 쓰고, 빈 탭과 뒤에서 열리는 링크는 필요할 때 페이지를 로드해 메모리 사용량을 줄입니다.

Windows 11 x64에서는 GitHub Releases에서 `FlitSetup-x64.exe`를 받아 설치할 수 있습니다. 명령으로 설치하는 방법과 소스 빌드 절차는 설치 안내에 있습니다. [0.41.0 다운로드](https://github.com/thisNorm/flit-browser/releases/tag/v0.41.0) · [설치와 빌드](installer/README.md)

Flit을 만든 이유와 Rust·Win32, Expo Exact, CEF를 각각 선택한 이유를 실제 RAM 측정과 함께 정리했습니다. [프로젝트 회고](PROJECT.md)

AI가 일반 창의 별도 작업 탭에서 페이지의 본문과 링크를 읽고, 지원되는 사이트에서는 Flit Vault로 로그인할 수 있다. [Codex 연결과 Vault 사용법](AGENT.md)

## 사용

- **⋯ → 설정(Settings)**에서 표시 언어, 북마크 가져오기, 검색 엔진, 시작 시 탭 복원과 백그라운드 링크 로드를 설정한다. 사이트 권한과 다운로드 설정은 같은 메뉴에서 Chromium의 해당 페이지를 바로 연다.
- **설정 → 표시 언어…**에서 한국어의 **이 언어로 Chromium 표시**를 선택한 다음 Flit의 모든 창을 종료하고 다시 실행한다. 이미 한국어를 선택했다면 다시 선택할 필요가 없다. 주요 Flit 메뉴·버튼과 Chromium 내장 화면이 한국어로 열린다. 웹사이트의 선호 언어는 언어 페이지에서 따로 조정할 수 있다.
- **설정 → Chrome 북마크 및 폴더 가져오기…**에서 로컬과 계정에 저장된 Chrome 북마크를 함께 가져올 수 있다. Edge 및 HTML 파일 가져오기도 설정에서 바로 열 수 있다.

- 주소창은 웹 주소와 검색어를 구분한다. `Ctrl+L`, `Alt+D`, `F6`으로 주소창으로 이동하고 `Enter`로 현재 탭에 연다. `Alt+Enter`는 현재 페이지를 그대로 두고 입력한 주소나 검색 결과를 새 탭에 연다. 조합 입력 중에는 입력기가 `Enter`·`Esc` 등을 먼저 처리한다. 확정된 주소창·검색 텍스트는 `Ctrl+Backspace`·`Ctrl+Delete`로 앞·뒤 단어를 지운다.
- 주소창을 입력하면 현재 창의 다른 탭과 저장한 북마크가 나타난다. `↑`·`↓`로 고르고 `Enter`로 열거나 후보를 클릭한다. `Esc`를 한 번 누르면 입력을 유지한 채 목록을 닫는다. `? ` 검색 모드는 검색어를 그대로 입력할 때 쓴다. 비공개 창의 후보는 해당 창의 열린 탭을 사용한다.
- `Ctrl+K`나 `Ctrl+E`를 누르면 주소창이 `? `로 시작한다. 주소처럼 보이는 내용도 검색하고 싶을 때 쓴다. `Esc`로 현재 페이지 주소로 돌아간다. **⋯ → 설정 → 검색 엔진**에서 DuckDuckGo, Google, Naver, Bing 중 기본 검색 엔진을 선택한다. 기본값은 DuckDuckGo다.
- 기본은 **왼쪽 세로 탭**이다. `Ctrl+T`로 새 탭, `Ctrl+W`·`Ctrl+F4` 또는 탭 오른쪽 ×로 닫는다. `Ctrl+Shift+T`로 이번 실행에서 닫은 일반 탭을 원래 순서와 고정 상태로 되돌리거나, 다른 일반 창이 남아 있으면 닫은 일반 창을 다시 연다. `Ctrl+Tab`·`Ctrl+Shift+Tab`으로 다음·이전 탭, `Ctrl+1`~`Ctrl+8`로 해당 탭, `Ctrl+9`로 마지막 탭으로 이동한다.
- **⋯ → Recently closed**에서는 이번 실행에서 닫은 탭이나 창 중 하나를 제목과 사이트 이름으로 골라 복원한다. 목록을 여는 동안 페이지는 로드되지 않는다. 비공개 창에서는 그 창에서 닫은 탭만 볼 수 있고, 창을 닫으면 목록도 사라진다.
- `Alt+Enter`나 웹페이지 링크로 열어 바로 선택된 새 탭을 닫으면, 그 탭을 열었던 페이지로 돌아간다. 출발 탭이 이미 닫혔으면 남은 탭 중 가까운 탭으로 이동한다.
- 왼쪽 탭을 끌면 삽입선이 나타난다. 탭 메뉴의 **Move tab up / down**으로도 순서를 바꿀 수 있다. 고정 탭과 일반 탭은 각 구역 안에서 옮기며, 복원이 켜져 있으면 순서가 다음 실행에도 유지된다.
- 탭 메뉴의 **Duplicate tab**은 현재 페이지를 원본 바로 옆에 열고 고정 상태를 이어받는다. 일반 창의 웹 탭을 우클릭하면 **Copy link**로 해당 탭의 주소를 복사할 수 있다.
- 다른 웹 탭을 우클릭해 **현재 탭과 분할 보기**를 선택하면 두 페이지를 나란히 볼 수 있다. `Ctrl+Shift+\`는 현재 웹 탭과 목록의 다음 웹 탭을 분할하거나 분할 보기를 끝낸다. 가운데 손잡이를 끌거나 포커스를 두고 방향키를 눌러 너비를 조정한다. 주소창과 탐색 버튼은 포커스된 페이지를 따른다. 두 페이지는 메모리 정리에서 보호되며, 일반 창의 세션 복원이 켜져 있으면 분할 상태와 너비도 저장한다.
- 탭을 클릭하면 키보드 입력이 웹페이지로 돌아간다. 왼쪽 목록에 포커스를 둔 채 방향키로 탭을 옮길 수 있고, `Enter`로 선택한 페이지에 포커스를 준다.
- 백그라운드 탭의 **× 옆 메모리 칩 아이콘**이나 탭 메뉴의 **Unload tab to free memory…**로 해당 탭을 정리한다. 페이지가 메모리에서 내려가도 주소·제목·고정 상태는 남는다. 다시 선택하면 페이지가 로드된다.
- 세로 탭 맨 아래의 **Free memory…**는 현재 창의 백그라운드 탭을 한 번에 정리한다. 확인창에서 동의할 때만 실행한다. 선택 중인 탭, 고정 탭, 유지하도록 설정한 사이트, 로딩·다운로드·카메라·마이크·DevTools를 쓰는 탭과 페이지를 떠날 때 경고하는 탭은 건너뛴다. 해당 탭의 뒤로·앞으로 가기 이력은 지워지며, 재생이나 경고 없는 임시 입력은 중단될 수 있다.
- 세로 탭에 마우스를 올리거나 키보드로 목록에 포커스를 두면 아래에 해당 페이지의 주 렌더러 RAM을 표시한다. 여러 탭이 렌더러를 공유할 수 있어 탭별 숫자를 합산하면 정확하지 않다. 평소에는 **live · on demand**가 열린 페이지 수와 선택하면 열릴 페이지 수를 보여 준다.
- 메신저처럼 유지할 사이트는 탭을 오른쪽 클릭해 **Keep [사이트] active when freeing memory**를 켠다. 일반 창 전체에서 같은 호스트에 적용되며 재시작 후에도 유지된다. 같은 항목을 다시 누르면 해제된다. 개별 탭을 직접 내리거나 비공개 창을 정리할 때는 적용되지 않는다.
- 새 프로필은 백그라운드로 연 링크를 선택할 때 로드한다. 메뉴에서 **Load background links only when selected**를 끄면 여유 RAM이 있을 때 최대 두 탭을 창 전체에서 미리 로드한다. 기존 프로필에 저장된 설정은 유지한다. **설정 → 메모리 절약**에서 오래 사용하지 않은 탭의 자동 정리 시간을 조절하거나 끌 수 있다. 기본값은 30분이며 시스템 RAM이 부족하면 더 일찍 정리할 수 있다.
- 같은 사이트의 여러 탭은 Chromium이 적합하다고 판단하면 렌더러를 더 일찍 재사용한다. 별도 설정 없이 동작하고, 보고 있던 탭을 닫지 않는다. 서로 다른 사이트에는 필요에 따라 별도 프로세스가 계속 생긴다.
- 갑작스러운 종료 후 마지막 저장 시점의 일반 창과 탭을 복원한다. 최대 16개 창의 위치·크기·최대화 상태와 창마다 최대 128개 탭의 주소·순서·고정 상태를 저장한다. 저장된 위치가 화면 밖이면 현재 모니터에서 보이도록 조정한다. 마지막 일반 창에서 선택된 페이지와 함께 보던 분할 페이지만 먼저 로드한다. 다른 복원 창은 전환할 때 해당 페이지를 로드한다. 비공개 창은 저장하지 않는다.
- 모든 창을 다음 실행에 이어가려면 **⋯ → Exit Flit (all windows)**로 종료한다. 창을 하나씩 **×**로 닫으면 마지막 일반 창만 남는다. 이전 실행의 복구본은 **⋯ → Open previous session backup**에서 현재 창을 유지한 채 열 수 있다. **Restore windows and tabs on startup**을 끄면 복원용 탭 기록을 지우고 다음에 빈 탭으로 시작한다.
- 일반적인 마지막 창 닫기와 **Exit Flit (all windows)**는 먼저 사이트의 닫기 경고를 처리한다. 경고에서 취소하면 열려 있던 작업이 그대로 남는다. 여러 창 중 한 창만 닫거나 다운로드가 진행 중이면 기존 닫기 방식이 적용된다.
- `Ctrl+N`은 새 일반 창, `Ctrl+Shift+N`은 비공개 창, `Ctrl+Shift+W`는 현재 창 닫기다. 비공개 창은 일반 창과 사이트 데이터를 공유하지 않는다. 마지막 비공개 창을 닫으면 비공개 사이트 데이터가 사라진다. 내려받은 파일은 남는다.
- 사용자가 클릭해서 여는 팝업은 원래 창과 통신할 수 있는 별도 창으로 연다. 새 탭에 결과를 여는 웹 양식은 입력값과 요청 방식을 유지한다. 최상위 페이지가 카메라·마이크를 요청하면 사이트 주소를 표시하고, **Allow this time**을 선택한 요청만 허용한다. 사용 중인 장치는 세로 탭과 활성 창 제목에 표시한다. 알림·화면 공유 등은 Chromium의 기본 확인창을 사용한다.
- `Ctrl+Shift+A`로 탭을 검색한다. 여러 단어를 입력하면 제목과 주소에서 함께 찾는다. `↑`·`↓`로 후보를 옮길 때는 현재 페이지를 유지하고, `Enter`를 누르면 강조된 탭을 연다. `Esc`는 탭을 바꾸지 않고 검색을 지운다. 목록 위 숫자는 검색 결과 수와 전체 탭 수다.
- 왼쪽 위 버튼이나 `Ctrl+Shift+B`로 패널을 열고 닫는다. 일반 창에서 마지막으로 고른 상태가 새 창과 다음 실행의 기본값이다. 움직이는 도중 다시 눌러 방향을 바꿀 수 있다. Windows에서 애니메이션을 끄면 즉시 전환한다.
- 페이지가 로딩되는 동안 새로고침 버튼은 **× (로딩 중지)**로 바뀐다. `Ctrl+R`·`F5`는 계속 새로고침으로 작동한다.
- `Ctrl+F`로 페이지를 검색하고 `F3`·`Ctrl+G`는 다음, `Shift+F3`·`Ctrl+Shift+G`는 이전 일치 항목으로 이동한다. `Ctrl+F5`로 캐시를 건너뛰어 새로고침하고 `F11`로 전체 화면을 전환한다. `Ctrl++`·`Ctrl+-`·`Ctrl+0`은 페이지 배율을 바꾸거나 초기화한다. 배율은 사이트별로 기억한다.
- 네이버처럼 넓은 화면을 전제로 만든 사이트가 좁은 창에서 잘리면 창을 최대화하거나, 왼쪽 패널을 접거나, `Ctrl+-`로 해당 사이트의 배율을 낮춘다.
- 별 버튼 또는 `Ctrl+D`로 현재 웹페이지를 북마크에 저장하고, `Ctrl+Shift+O`로 북마크 관리 화면을 연다. 다른 브라우저에서 내보낸 북마크 HTML을 **⋯ → Import bookmarks from HTML…**에서 골라 추가할 수 있다. Flit에서 백업할 때는 **Export bookmarks to HTML…**을 누른다. 두 메뉴는 일반 창에서만 사용할 수 있다.
- 왼쪽 북마크를 누르면 해당 북마크 자리에서 페이지가 열린다. 열린 북마크는 다시 눌러 현재 페이지로 돌아갈 수 있다. 북마크 줄의 ×나 Ctrl+W로 페이지를 닫아도 저장된 북마크는 남는다.
- 일반 창에서 `Ctrl+Shift+D` 또는 **⋯ → Bookmark all tabs…**를 눌러 현재 창의 웹 탭을 한꺼번에 저장한다. 확인을 누르면 북마크 관리자의 **Other bookmarks** 아래 날짜와 시각이 붙은 새 폴더가 생긴다. 같은 주소는 한 번만 저장하고, 대기 중인 탭은 선택하기 전까지 로드하지 않는다.
- **⋯ → Move sites and bookmarks**에서 Chrome·Edge의 북마크를 파일 내보내기 없이 옮기거나, 그 사이트를 세로 탭에 준비한다. 다른 브라우저에서 복사한 사이트 주소도 여러 개 추가할 수 있다. 준비한 탭은 선택할 때 로드한다. [사이트와 북마크 옮기기](MOVE-SITES.md)
- 주소창 오른쪽의 다운로드 버튼에서 최근 파일의 크기와 완료 시점, 전송 중인 파일의 진행률을 볼 수 있다. 패널에서 파일이나 폴더를 열고 전송을 일시 중지·재개·취소할 수 있다. `Ctrl+J`는 전체 다운로드 기록을 연다. 비공개 창의 툴바 목록에는 그 창에서 받은 파일만 표시한다.
- 다운로드 중인 탭을 닫을 때 **Yes**를 누르면 전송을 마친 뒤 닫힌다. 기다리는 탭에는 **After download**가 표시되고, 우클릭 메뉴의 **Keep tab open after downloads**로 예약을 취소할 수 있다. 전송에 실패하거나 취소되면 탭이 남는다. 다운로드 중 창을 닫거나 Flit 전체를 종료할 때는 확인 메시지가 뜬다.
- 도구 줄의 확장 프로그램 버튼에서 설치된 확장을 실행하거나 **확장 프로그램 관리**를 연다. 신뢰하는 로컬 확장 폴더는 관리 화면의 **Developer mode → Load unpacked**로 추가할 수 있다. Chrome 웹 스토어 직접 설치와 주소창 고정은 지원하지 않는다.
- 일반 창의 도구 줄에서 열쇠 버튼을 누르면 현재 HTTPS 사이트의 **로그인 보관함**이 열린다. 여기서 로그인 저장 여부를 확인하고 등록하거나 삭제한다.
- 주소창 왼쪽 버튼으로 현재 사이트의 연결 상태를 보고, 일반 창에서 해당 사이트 설정을 바로 열 수 있다. `Ctrl+Shift+Delete`는 인터넷 사용 기록 삭제다. 일반 설정과 기록 삭제는 별도 창에서 열리므로 현재 탭을 그대로 볼 수 있다.
- `F12`·`Ctrl+Shift+I`로 현재 탭의 개발자 도구를 열고 닫으며, `Ctrl+Shift+J`로 콘솔을 연다. 메뉴에서 방문 기록, 비밀번호 관리자, 확장 관리, 인쇄도 열 수 있다.
- 다른 브라우저에서 내보낸 아이디와 비밀번호는 일반 창의 **⋯ → Import passwords from CSV… → Select file**에서 가져온다. [지원 형식과 옮기는 방법](PASSWORD-IMPORT.md)
- 좁은 창에서는 창 조작 버튼을 위쪽 줄에 두어 주소와 검색어를 입력할 공간을 확보한다. 주소창과 페이지 찾기 안에서도 Tab으로 버튼에 접근할 수 있다.
- Windows 11 22H2 이상에서는 창 프레임에 Mica Alt를 요청한다. 메뉴에서 **Use acrylic window frame**을 선택하면 해당 실행에서 Desktop Acrylic을 요청한다. Windows의 투명 효과와 고대비 설정에 따라 단색이 될 수 있다. 주소창·탭 텍스트와 웹 콘텐츠는 불투명하게 유지한다.
- **About Flit and updates**에서 버전과 업데이트 채널 상태를 확인한다. [자동 업데이트](installer/UPDATES.md)는 서명 키와 배포 저장소를 지정한 빌드에서만 켜진다. 지금 제공한 개발 미리보기에는 실제 업데이트 채널을 연결하지 않았다.
- 기본 프로필은 `%LOCALAPPDATA%\Flit Browser\User Data`에 저장된다. 제거해도 프로필은 남는다. 기존 Chrome·Aside 프로필을 열거나 복사하지 않는다.

## 범위

새 탭, 설정, 주소창 후보, 도구 메뉴, 다운로드 목록, 확장 목록, 로그인 보관함과 저장 확인은 **Expo Exact**로 표시한다. 주소 입력, 세로 탭과 분할 너비 조절은 **Rust + Win32**, 웹페이지와 확장 콘텐츠는 **CEF Chrome Runtime 158.0.3**이 맡는다. [창 UI와 메모리 설계](DESIGN.md)

Chrome 웹 스토어 직접 설치와 패스키는 지원하지 않는다. AI 작업 탭은 읽기·링크 이동·일부 HTTPS 폼 로그인을 지원한다. 기존 사용자 탭 인계와 다단계 로그인은 지원하지 않는다. 카메라·마이크 확인창은 가상 장치로 검사했으며 알림 허용·실제 화면 공유는 검증하지 않았다. 복원은 URL을 다시 여는 기능이며, 페이지 내부 입력이나 뒤로 가기 이력은 복원하지 않는다. 현재는 서명되지 않은 개발 미리보기다.

## 빌드

Windows에서 Rust의 MSVC 도구 체인과 Visual Studio C++ Build Tools(Windows SDK 및 CMake 포함)를 준비한다. 저장소 루트에서 x64 개발자 PowerShell을 연다. [Rust CEF 바인딩](https://github.com/tauri-apps/cef-rs/tree/9aa78c450489eddb828eb982eaee6c104a89d348) `156.4.0+156.0.26`과 Rust `1.100.0`으로 API `15600`을 대상으로 검증했다.

~~~powershell
rustup target add x86_64-pc-windows-msvc
$env:CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_RUSTFLAGS = '-C target-feature=+crt-static'
cargo test --release --locked --target x86_64-pc-windows-msvc --lib
cargo build --release --locked --target x86_64-pc-windows-msvc
~~~

Rust 빌드 결과는 `target/x86_64-pc-windows-msvc/release/flit.dll`이다. Exact DLL은 `tools/Build-ExactUi.ps1`로 빌드한다. 이 스크립트는 `native-ui/ExactRevision.txt`에 고정한 코드를 사용한다. [설치 파일 빌드 안내](installer/README.md)에 따라 CEF 런타임과 함께 실행 번들을 준비한다. `tests/windows_*.py`는 별도 테스트 프로필로 실행한다. 예를 들어 저장소 루트에서 아래처럼 다운로드 UI를 검사할 수 있다.

~~~powershell
python tests/windows_downloads_toolbar.py --exe .\bundle\Flit.exe --work .\work
~~~
